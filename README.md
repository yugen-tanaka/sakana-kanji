# 魚偏漢字クイズ 〜すし処 魚偏亭〜 🍣🐟

魚偏（うおへん）のつく漢字に特化した、本格お寿司屋さん風3択漢字クイズWebアプリケーションです。

## 特徴
- 🍣 **魚偏の漢字特化**: 初級・中級・上級の豊富な魚偏漢字（鯛、鮪、鮭、鯖から鱰、鰰まで）を網羅。
- 🎯 **3択マルチプルチョイス**: 直感的にサクサク回答できる3択形式。
- 🔄 **出題方向の切り替え**: 「漢字 → 読み」と「読み → 漢字」の双方向モードに対応。
- 🎚️ **難易度デュアルスライダー**: 上端と下端を自由に設定可能。重複（初級のみ、中級のみ等）可能・交差不可。
- 🖌️ **本格和風・毛筆デザイン**: Google Fonts `Yuji Boku` による味わい深い毛筆フォント、暖簾や寿司下駄をモチーフにしたUI。
- 🔊 **和風効果音**: Web Audio API による拍子木や和太鼓の心地よいサウンド演出（消音機能付き）。
- 📜 **お勘定番付表**: スコアと難易度に応じた板前称号と、間違えた漢字の復習リスト。

## 開発環境のセットアップ

### インストール
```bash
pnpm install
```

### 開発サーバー起動
```bash
pnpm run dev
```

### ビルド
```bash
pnpm run build
```
